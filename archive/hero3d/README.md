# Hero 3D 场景存档（D4 落选候选）

> 定稿时间：2026-10-25，D4 最终选定「时间算法」为官网 Hero 3D 场景。
> 本目录保存落选的六个候选场景的完整代码快照（`.tsx.txt` 后缀，不参与编译），
> 以及七场景版本的装配代码，供日后想换回或混搭时取用。

## 落选场景清单

| 场景 | 快照文件 | 说明 |
|------|---------|------|
| 洛伦兹风暴眼 / 向量场之茧 | `sceneExtras.洛伦兹与向量场.tsx.txt` | 两个场景的完整实现 |

| 七场景切换器 / 红移专属配色 | `Hero3DLoader.七场景切换版.tsx.txt` | 开发模式小样切换器与配色系统 |

## 如何恢复某个场景

1. 从对应快照里复制场景组件（如 `WavesLayer`）到 `src/components/hero3d/` 下并去掉 `.txt` 后缀；
2. 在 `HeroScene.tsx` 的 Canvas 里加回对应的渲染分支（参考 `HeroScene.七场景版.tsx.txt` 里的写法）；
3. 依赖的公共设施（`SoftLayer`、`interaction.ts`、`ANIM_SPEED`）在现役代码里都有，直接可用；
4. 想临时对比多个场景，可参考 `Hero3DLoader.七场景切换版.tsx.txt` 恢复开发模式切换器。
